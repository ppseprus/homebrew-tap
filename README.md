# ppseprus/homebrew-tap

A personal [Homebrew](https://brew.sh) tap.

## Formulae

- **[git-exclude](https://github.com/ppseprus/git-exclude)** — manage `.git/info/exclude` from the command line, as `git exclude`. Keeps your own notes and working files in a repository without committing them.

## How do I install these formulae?

```sh
brew install ppseprus/tap/git-exclude
```

Or tap once and then install by name:

```sh
brew tap ppseprus/tap
brew install git-exclude
```

Or in a [`brew bundle`](https://github.com/Homebrew/homebrew-bundle) `Brewfile`:

```ruby
tap "ppseprus/tap"
brew "git-exclude"
```
